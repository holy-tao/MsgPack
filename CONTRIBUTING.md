# Contributing

Contributions are welcome! Start off by reviewing the [MessagePack specification](https://github.com/msgpack/msgpack/blob/master/spec.md). It is fairly straightforward, but working with it in AHK requires moderate-to-advanced knowledge of bit and buffer manipulation. 
You may want to peruse some of the other MessagePack implementations listed on the [website](https://msgpack.io/) for inspiration.

Changes must be submitted via pull requrests. Tests must pass. New functionality must be tested. Etc, etc.
